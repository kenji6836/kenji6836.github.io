Instagram 運用テンプレート（架空のカフェ）

自主制作SNS運用マーケティング2025

自家焙煎カフェを想定した架空ブランドで、投稿テンプレート 3 型・9 投稿・月間カレンダー・月次レポートの雛形まで一式を制作。担当者が型に沿って回せる運用設計。

ポイント

  • 「商品」「豆知識」「お知らせ」の 3 型で、投稿の迷いをなくす
  • 9 投稿を並べたときの配色バランスまで設計したフィード
  • 月間カレンダーと月次レポートの雛形で、運用を引き継げる形に
担当
運用設計・テンプレート設計・投稿制作・レポート雛形
技術
  • HTML / CSS / SVG
  • Google Fonts
  • スプレッドシート運用
前の実績: バナー広告セット（架空の外壁塗装店）次の実績: App Store 掲載最適化（ASO）
