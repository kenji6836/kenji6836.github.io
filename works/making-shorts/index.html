縦型ショート動画シリーズ「MAKING」（3 本）

自主制作動画制作SNS運用マーケティング2026

Claude Code で作った実物（紹介 HP・Web アプリ・夜間の自律ランナー）の制作過程を、各 26 秒の縦型ショートに。YouTube Shorts・Reels・TikTok に同じ素材で投稿できる字幕焼き込み・無音でも伝わる構成。BGM は自作合成。

ポイント

  • 「実物 → 日本語で頼む → 生成 → 確認 → 公開」の 5 ビートを 3 本で共通化し、シリーズとして続けられる型に
  • 数字は実物の台帳から引いた実数のみ（19 ページ生成・自動テスト 235 項目・1 日 7 回の実行枠 など）
  • 共通のイントロ 2 秒／アウトロ 3 秒をブランド素材として分離し、次回以降は本編だけ作れば済む
担当
企画・構成・モーション制作・字幕設計・BGM 合成・書き出し
技術
  • HTML / CSS アニメーション
  • headless Chrome フレーム書き出し
  • ffmpeg（H.264 / VP9・AAC / Opus）
  • Python（BGM 合成）
前の実績: アプリ紹介ショート動画（15 秒・縦型）次の実績: バナー広告セット（架空の外壁塗装店）
