  • チップ: 高さ 22・横 8・11.5px/700・角丸 999。種別＝青枠、概算帯＝灰枠、緊急度＝至急のみ赤地＋三角、状態＝未対応（琥珀＋点）/ 作業中（青＋点）/ 返信済（緑＋チェック）。
  • ボタン: 高さ 34（sm 28）・横 14（sm 10）・13px/700。主操作は 1 画面 1 つ。アイコンは 16px・stroke 1.75。
  • デモ帯: 高さ 36・琥珀地・左に三角・右端リンク。モバイルでは 2 行折返し・リンク非表示。
  • 受信箱の行: 左 3px の帯＝至急、未読は青点、差出人 13px/700・件名 14px/700・抜粋 12px、チップ列は折返し可。選択行は --brand-soft ＋ aria-current="true"。

使い分け・ease・reduced-motion
  • ease: cubic-bezier(.2,.7,.2,1)。160ms: hover の背景・枠・文字色、チップの出現。
  • 240ms: ペインの切替、トーストの上昇、パネルの開閉。
  • prefers-reduced-motion: アニメーション/トランジションを .001ms に。スケルトンは静止、スピナーは止まった弧のまま意味が通る。
  • hover は色のみ（拡大しない）。押下は 1px 沈む。disabled は 50% 不透明＋ cursor not-allowed。

キーボードと読み上げ
  • 受信箱: ↑↓ で行移動・Enter で開く・/ で検索・Esc で戻る。行は role="option" ＋ aria-selected。
  • 3 ペインは header → nav → main → aside の順にタブ移動。スキップリンクで main へ。
  • チップの意味は aria-label（例「緊急度: 至急」）で補い、色名は読ませない。
  • トーストは role="status"（割り込まない）。エラーは aria-invalid ＋ aria-describedby。
  • フォーカスリングは outline:2px solid var(--brand); outline-offset:2px。チップ・行・タブにも同じ。
  • ブラウザ拡大 200% で横スクロールが出ない（minmax(0,1fr) と折返し）。
